|特性|数组（Array）|切片（Slice）|映射（Map）|
|---|---|---|---|
|长度|固定（声明时确定，是类型的一部分）|动态可变（可通过append增长）|动态可变（键值对数量可增删）|
|容量|与长度相等（固定）|动态可变（>=长度，可预分配优化性能）|无“容量”概念，内部有哈希表扩容机制|
|类型性质|值类型（赋值/传参会复制整个数组）|引用类型（指向底层数组，赋值/传参复制引用）|引用类型（赋值/传参复制引用）|
|核心用途|固定长度的同类型元素存储|动态长度的列表、集合（最常用）|键值对映射、快速查找（O(1)复杂度）|
|声明/初始化方式及示例|仅声明：var arr [3]int（元素为零值）初始化：1. 完整初始化：arr := [3]int{1, 2, 3}2. 长度自动计算：arr := [...]int{1, 2}（长度为2）3. 指定索引初始化：arr := [5]int{1:10, 3:30}（索引1和3赋值，其余为0）|仅声明：var sl []int（值为nil，长度0，容量0）初始化：1. 字面量初始化：sl := []int{1, 2}（长度2，容量2）2. make初始化：sl := make([]int, 0, 10)（长度0，容量10，预分配优化）3. 从数组/切片截取：sl := arr[1:3]（基于数组arr创建切片）|仅声明：var m map[string]int（值为nil，不可直接操作）初始化：1. 字面量初始化：m := map[string]int{"a":1, "b":2}2. make初始化：m := make(map[string]int, 5)（指定初始容量5，减少扩容）|
|访问方式|通过索引访问（如arr[0]）|通过索引访问（如sl[1]）|通过键访问（如m["key"]）|
|能否直接比较|可以（长度相同且元素均相等时为真）|不可以（仅能与nil比较）|不可以（仅能与nil比较）|
|零值|长度固定的空数组（元素为对应类型零值）|nil（长度0、容量0的空切片）|nil（未初始化的空映射，不能直接操作）|
|扩容机制|不支持（长度固定）|自动扩容（容量不足时分配新底层数组）|自动扩容（哈希表负载过高时重建）|

- 以下是打印输出数组、切片和 map 的示例代码，包含具体输出结果：
```
package main

import "fmt"

func main() {
    // 1. 数组
    arr := [3]int{10, 20, 30}
    fmt.Println("数组:")
    fmt.Println(arr)         // 直接打印数组
    fmt.Printf("%#v\n", arr) // 带类型信息的打印

    // 2. 切片
    sl := []string{"a", "b", "c"}
    fmt.Println("\n切片:")
    fmt.Println(sl)         // 直接打印切片
    fmt.Printf("%#v\n", sl) // 带类型信息的打印

    // 3. map
    m := map[int]string{1: "one", 2: "two", 3: "three"}
    fmt.Println("\nmap:")
    fmt.Println(m)         // 直接打印map（注意：输出顺序可能不固定）
    fmt.Printf("%#v\n", m) // 带类型信息的打印
}
```

```

[3]int{10, 20, 30}

切片:

[]string{"a", "b", "c"}

map:
map[1:one 2:two 3:three]  // 实际输出顺序可能不同（map无序）
map[int]string{1:"one", 2:"two", 3:"three"}
```
