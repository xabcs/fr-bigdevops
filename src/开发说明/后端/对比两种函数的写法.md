### 第一种

```
func GetAllMenulist() ([]*Menu, error) {
  var menus []*Menu
  err := Db.Find(&menus).Error
  if err != nil {
  	return nil, err
  }
  return menus, nil
}
```

### 第二种

```
func GetAllMenulist2() (menus []*Menu, err error) {
	err = Db.Find(&menus).Error
	return
}
```


| 维度           | GetAllMenulist                                                                                                 | GetAllMenulist2                                                                                                                                                   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **函数签名**   | func GetAllMenuList()([]*Menu,error)                                                                           | func GetAllMenuList2()(menu  []*Menu,err error)                                                                                                                   |
| **返回值声明** | **常规声明**:仅声明返回值类型（`[]*Menu` 和 `error`）内部手动声明变量 `menus` 和 `err`，最后显式返回这两个变量 | **命名返回值**；声明返回值的**变量名 + 类型** （`menus`、`err` 为命名返回值）这些变量会被视为函数内部的局部变量，可直接赋值，最后用 `return` 隐式返回所有命名变量 |
| **变量定义**   | 需在函数内部手动声明`menus` 变量（`var menus []*Menu`）                                                        | 无需手动声明，命名返回值自动成为函数内部局部变量                                                                                                                  |
| **返回语句**   | 显式返回变量（`return menus, err`）                                                                            | 可简化为`return`（隐式返回所有命名返回值）                                                                                                                        |
| 实现逻辑       | 声明局部变量`menus` 和 `err`，执行数据库查询并复制给err,显式返回menus和err<br />                               | 在函数签名中声明返回值变量menus和err,执行数据库查询并直接复制给err,用return直接返回（隐式返回所有声明的返回值）                                                   |


两种写法中的 `menus` 和 `err` 都是函数内部的局部变量，作用域仅限于函数内部，无本质区别
